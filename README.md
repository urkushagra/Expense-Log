# 💸 ExpenseLog Pro

A modern and responsive expense tracking web application built using **HTML, CSS, and Vanilla JavaScript**.

Track your income, expenses, balance, and transactions with a clean dashboard UI and local storage support.

---

# 🚀 Features

✅ Add & delete transactions  
✅ Track income and expenses  
✅ Real-time balance calculation  
✅ Search transactions instantly  
✅ Persistent data using LocalStorage  
✅ Dark modern UI  
✅ Responsive layout  
✅ Modular JavaScript architecture  
✅ Light/Dark theme toggle
